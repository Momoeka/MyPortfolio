\begin{rSection}{PROJECTS}
\begin{itemize}[itemsep=4pt, topsep=0pt, parsep=0pt, partopsep=0pt]
    \item \textbf{AgentLens -- AI Agent Observability \& Safety Platform} \hfill \href{https://agent-lens-gamma.vercel.app/}{Live}\\
    SaaS that intercepts every tool call an AI coding agent makes. A published npm CLI auto-detects installed agents -- Claude Code, Cursor, Cline, Antigravity -- and installs hooks that buffer and queue calls to the ingest API. Each call is rewritten into one plain-English line for non-technical readers and classified \textit{safe} / \textit{risky} / \textit{destructive} by a three-provider LLM chain (Gemini 2.0 Flash to GPT-4o-mini to Claude Sonnet) with 8-second timeouts and automatic failover; destructive calls escalate the session's risk level and trigger email alerts. 38 typed server actions across 9 modules, 9 REST routes and 17 migrations, with team RBAC and invites, Redis rate limiting, plan gating, session diffing and CSV/PDF export.\\
    \textit{Next.js 16, React 19, TypeScript, Supabase, Clerk, Upstash Redis, Resend.}

    \item \textbf{Legal Case-Management CRM -- Rowan Rose Solicitors}\\
    Runs the full irresponsible-lending claim lifecycle: intake, letter of authority, data subject access request, complaint, final response and ombudsman escalation. AI workers read lender DSAR packs and Final Response Letters with Gemini 2.5 Pro and Tesseract OCR, classify every loan into one of five outcome categories against a versioned deterministic ruleset, and compile complaint letters behind a hard client-identity verification gate. Inbound mail across four Outlook mailboxes is classified by a self-hosted model, actioned by channel workers and filed automatically. Includes a visual automation studio, document generation and e-signature, payment reconciliation and self-hosted team chat.\\
    \textit{Node.js, Express, PostgreSQL, React, AWS S3, Microsoft Graph, Puppeteer, docxtemplater.}

    \item \textbf{Sales CRM with VoIP \& Lead Distribution}\\
    Lead pipeline where agents dial from the browser over SIP.js with RNNoise WASM noise suppression, supervisor call listening, Twilio SMS and a Socket.IO live floor monitor. A distribution engine maintains each agent's lead pot -- a daily sweep plus continuous top-up, priority and age ordering, protected statuses so closed work is never reclaimed, and a dry-run mode that plans without writing. 108 endpoints and 65 React components.\\
    \textit{Node.js, PostgreSQL, React, Twilio, SIP.js, Socket.IO.}

    \item \textbf{DocIntel -- Multi-Tenant Document Intelligence SaaS}\\
    Upload an invoice, consignment note or ID and get back structured, schema-mapped data. A Celery pipeline classifies the document, renders PDF pages at 300 DPI and sends each page to a vision-language model on AWS Bedrock (Qwen3-VL 235B), which returns the mapped fields, unrecognised extras and a normalised bounding box for every value, with a Redis semaphore throttling concurrent model calls. Extracted keys resolve against the tenant schema by exact match, then alias, then 88\% similarity, with anything else parked as a candidate field for review. Human corrections made at verification are stored as weighted examples and fed back into later prompts, improving extraction accuracy per tenant over time. 73 endpoints, five-level role hierarchy, tenant-isolated queries, confidence-threshold auto-approve and Excel/CSV export.\\

JWT held in signed httpOnly cookies with a per-request database check, so disabling an account revokes live sessions instantly instead of waiting for token expiry; bcrypt at cost 12, single-use SHA-256 reset tokens and Cloudflare Turnstile on every public form. Device identities and telemetry packets are cached locally so dashboards and analytics render without consuming upstream tracking-API quota. Admin console for registration approval, device assignment and user management across 37 endpoints.\\
    \textit{Node.js, Express, PostgreSQL on RDS, React, Vite, AWS EC2, nginx, PM2.}
